# Portfolio Website Plan: Data Analyst

## Goal
Build a modern, dark-themed portfolio website for a Data Analyst & Engineer.

## Specs
1.  **Theme:** Modern dark theme.
2.  **Typography:** JetBrains Mono.
3.  **Hero:** Name: "Kritamet Seesaen", Title: "Data Analyst and Engineer".
4.  **Projects:** 3 project showcases.
5.  **Contact:** Clear contact details/links.

## Step-by-Step Plan

### 1. Setup Phase
- [ ] Create public repository `portfolio` (or `username.github.io`) on GitHub.
- [ ] Initialize local files: `index.html`, `style.css`, `script.js`, and `assets/`.

### 2. Design Strategy
- [ ] **Dark Theme:** Use deep backgrounds (`#0f172a`) and light text (`#f8fafc`).
- [ ] **Typography:** Import "JetBrains Mono" via Google Fonts.
- [ ] **Layout:** Hero section (Flexbox), 3-column project grid (responsive), and contact footer.

### 3. Development Phase
- [ ] **Structure:** Semantic HTML5 (`header`, `hero`, `projects`, `footer`).
- [ ] **Styling:** CSS variables for colors, set font, responsive grid layout.
- [ ] **Content:** Add personal info and project summaries.
- [ ] **Refinement:** Add hover effects and smooth scrolling.

### 4. Deployment Phase
- [ ] **Git:** Commit and push to `main` branch.
- [ ] **GitHub Pages:** Enable via **Settings > Pages > Deploy from branch**.
- [ ] **Verify:** Visit `https://<username>.github.io/portfolio/`.
